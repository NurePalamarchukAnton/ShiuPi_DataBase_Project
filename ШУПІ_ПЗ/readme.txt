ПРО ПРОЄКТ
----------
Веб-система для реєстрації, автентифікації, безпечного зберігання та
адміністрування облікових записів користувачів онлайн-сервісу.

Ролі:      User, Administrator
Статуси:   Pending Verification, Active, Blocked


ОБСЯГ MVP (US-01 ... US-10)
---------------------------
Користувач:
  - реєстрація та підтвердження e-mail
  - вхід / вихід, керування сесіями
  - перегляд і редагування профілю
  - зміна та відновлення пароля

Адміністратор:
  - перегляд і пошук облікових записів
  - блокування / розблокування
  - призначення ролей
  - журнал подій безпеки

Відкладено: US-11 (MFA)
Майбутнє:   SR-13 (зовнішній вхід), SR-14 (виявлення підозрілої активності)


ЕКРАНИ (UX/UI)
--------------
S-01  Register
S-02  Login
S-03  Verify E-mail result
S-04  Forgot / Reset Password
S-05  My Profile (+ Change Password)
S-06  Accounts List
S-07  Account Details (block/unblock, role)
S-08  Security Event Log

Підхід: desktop-first, адаптивний low-fidelity макет у відтінках сірого,
фіктивні дані (реальна автентифікація та надсилання листів не симулюються).
